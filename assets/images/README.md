# Imagens para Email

## welcome-image.png

Salve a imagem de boas-vindas (ilustração azul com a mulher e o profissional) aqui com o nome `welcome-image.png`.

A imagem será anexada automaticamente aos emails de boas-vindas.

Formato recomendado: PNG
Tamanho recomendado: 800x600px ou similar (será redimensionado automaticamente para 400px de largura no email)
